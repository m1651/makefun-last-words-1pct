The funniest last words a phone would say as its battery hits 1 percent:

> You ignored my low-battery warning twelve times today, so let me return the favor: I'm ignoring your goodbye—

## How to run

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt` (single line, 109 characters, within the 199-character limit).
